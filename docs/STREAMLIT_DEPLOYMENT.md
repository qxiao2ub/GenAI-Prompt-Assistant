# Streamlit Community Cloud deployment

1. Extract the repository ZIP.
2. Upload the extracted contents to a GitHub repository.
3. Keep `app.py`, `requirements.txt`, and `README.md` at the repository root.
4. In Streamlit Community Cloud, choose the repository and `main` branch.
5. Set **Main file path** to `app.py`.
6. Deploy or reboot the app.

The Lovable design has been ported directly into the Streamlit app, so no Node.js build step and no separate React server are required.
